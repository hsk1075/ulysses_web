# 율리시스

왼손과 홍양이 사진으로 주고받은 6개의 트랙을 보관하는 사진 아카이브.

## 구조
- `index.html` : 화면 구조 (HTML)
- `css/style.css` : 디자인 (CSS)
- `js/data.js` : 사진 목록 (여기만 수정)
- `js/script.js` : 동작 (JavaScript)
- `images/logo.png` : 로고
- `photos/` : 사진 파일

## 사진 추가
`photos/l1/01.jpg` 처럼 파일을 넣고 `js/data.js` 의 해당 트랙 `photos` 배열에 경로를 순서대로 적으면 됩니다.
다음 사진이 가로면 오른쪽, 세로면 아래로 자동 배치됩니다.

## GitHub Pages
저장소 Settings → Pages 에서 브랜치를 선택하면 바로 게시됩니다.
